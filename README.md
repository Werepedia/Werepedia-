# Werepedia
https://werepedia.com

Werepedia is a multilingual reference guide for the game Werewolf (Mafia) on Plato.

It provides clear explanations of roles, rules, and gameplay variations in:
- English
- Spanish
- French
- Portuguese

The goal of Werepedia is to offer a structured and easy-to-navigate knowledge base for players.

Topics:
werewolf game, mafia game, plato, social deduction, party games, role explanations, game rules
